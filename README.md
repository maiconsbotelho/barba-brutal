# Barba Brutal

**Barba Brutal** é uma aplicação desenvolvida para uma barbearia, oferecendo uma plataforma online para agendamentos de serviços, visualização de serviços oferecidos e informações de contato da empresa. A aplicação é projetada para proporcionar uma experiência intuitiva e eficiente para os clientes, com um design responsivo que se adapta a diferentes dispositivos.

O projeto é desenvolvido em TypeScript, utilizando **Next.js** para o front-end e **Nest.js** para o back-end, com PostgreSQL como banco de dados. A interface é estilizada com **Tailwind CSS** para uma aparência moderna e adaptável.

**Experimente a aplicação [Barba Brutal](https://maiconbotelho-barbabrutal.vercel.app/)**!

## Funcionalidades

- **Agendamentos Online**: Permite aos clientes agendar serviços diretamente pela plataforma.
- **Visualização de Serviços**: Os clientes podem explorar os diferentes serviços oferecidos pela barbearia.
- **Informações de Contato**: Detalhes de contato da barbearia são facilmente acessíveis.
- **Design Responsivo**: Garantia de uma experiência consistente em diferentes dispositivos, desde desktops até dispositivos móveis.
